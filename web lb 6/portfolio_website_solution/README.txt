PORTFOLIO WEBSITE - LAB SHEET 6 SOLUTION

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted portfolio_website_solution folder.
3. Double-click index.html, or open it with Chrome/Firefox/Edge.
4. Use the navigation to visit Home, About, Projects and Contact.

FILES
- index.html      Home page
- about.html      About page
- projects.html   Project gallery, search filter and pricing cards
- contact.html    Contact form and FAQ accordion
- styles.css      External responsive CSS
- script.js       JavaScript interactions
- assets/         Local SVG illustration assets

LAB SHEET FEATURES INCLUDED
1. Four-page portfolio with semantic HTML5 structure.
2. External CSS with Flexbox navigation and card layouts.
3. Responsive hero banner with background image overlay and CTA.
4. Mobile hamburger menu.
5. CSS Grid photo/project gallery with hover zoom.
6. Contact form validation (name, email and message).
7. Dark/light mode toggle using CSS root variables.
8. Pricing cards with popular plan highlight and hover elevation.
9. Smooth scrolling for in-page anchor links.
10. FAQ accordion.
11. JavaScript-array-powered testimonials slider.
12. Flexbox social links in footer.
13. Floating Back to Top button.
14. Mobile, tablet and desktop media queries.
15. Statistics counter animation using IntersectionObserver.
16. Feature grid with custom text/vector-style icons.
17. Modal popup behavior is implemented in script.js and can be connected to
    an element with id="open-modal" and a modal with id="portfolio-modal".
18. Print stylesheet using @media print.
19. Live project search filter.

NOTE
The contact form is a front-end demonstration only. It validates input in the
browser but does not send email or store submitted data. Replace sample name,
email, social links, text and pricing with your own details.
